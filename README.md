## Core Patterns

- **Chomsky Vase First**: Vase-First Scaffolding: build the type contracts, error envelopes, and lifecycle guards (the vase) before domain logic (the flowers).
- **Practical Application**: Building robust concurrent pipelines and fault-tolerant network clients.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
